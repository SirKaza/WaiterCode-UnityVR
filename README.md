# TFG - Waiter Code Unity VR

**Virtual Reality Serious Videogame Final Degree Project**

## 2.1. Main Objective

The main objective of this project is to enhance the existing **“Waiter”** game mode in the video game **Cooking Code**. The project aims to:

* Refine and fix current features.
* Implement new gameplay mechanics.
* Integrate a conversational agent to evaluate the game, making it a **more engaging and effective serious game**.

---

## 2.2. Specific Objectives

The main objective can be broken down into the following sub-objectives:

1. **Learn and research Unity and C#** to implement the game improvements.
2. **Familiarize with Oculus Quest and Virtual Reality (VR)** technologies.
3. **Analyze similar video games** to understand best practices and gameplay trends.
4. **Understand the design and implementation** of the **Cooking Code** mode.
5. **Understand the design and implementation** of the **Waiter Code** mode.
6. **Perform an in-depth analysis of Restaurant Code**, fixing existing errors to establish a solid foundation for the project.
7. **Design and develop new game mechanics** to enhance player experience.
8. **Learn and experiment with MongoDB and Atlas DB** for data management.
9. **Understand Conversational Agents** and their functionalities.
10. **Study and integrate the Rasa conversational agent**, along with a voice service, enabling **voice-based interaction** within the game.
